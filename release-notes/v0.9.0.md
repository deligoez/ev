Gridfinity drawers as grids: a drawer knows its cells, each box knows which ones it covers, and
`ev grid` draws the map with the free cells.

## New

- **Grids.** `ev grid K4x4-07-A --cols 6 --rows 7` lays a drawer out in cells — columns A… from
  the left, rows 1… from the back. `ev cell 07-A-A3=A3-B3 07-A-C4=C4` places boxes in it; the
  cells used to live only in each box's note. `ev grid K4x4-07-A` draws the drawer with every
  cell labelled by the box in it, lists the free cells and the things in the drawer not placed
  in a cell, and `ev ui` shows the same map in the details of the drawer.
- **Boxes trade places in one step.** `ev cell` checks bounds and overlaps against where every
  box ends up, so moving a tall box back a row and the two boxes there forward is one command,
  and `--recode` renames each box after its back-left cell (`K4x4-07-A-A3`), marking the new
  labels to print.
- **Room for a new box.** `ev show` carries a box's `cells` and a drawer's `grid`, and
  `ev suggest` lists each grid drawer's free cells, so a place for a new box can be named by
  cell.

## Changed

- **The first tab of `ev ui` is Layout (Yerleşim)**, not Tree (Ağaç): it shows where things
  are.
- The database moves to schema version 8 on first use; older `ev` builds refuse it (exit 6).

A fix found on the first real inventory: a set could not be sent away as a set.

## Fixed

- **A bundle can now be disposed and leave together.** Selling a dock together with its adapter and
  cables meant putting the parts inside the dock record and marking each for sale, but the dock
  itself was then refused because it "still held" nodes, even though every one of them was already
  set aside. `dispose` and `gone` now refuse only when something *active* is inside. When a node
  leaves, the candidates inside it leave with it, each keeping its own disposition, and each part's
  `gone` event names the node it left with.

## Upgrade notes

- No schema change; an existing `~/.ev/ev.db` works as is.
- The refusal message now reads "still holds N active node(s)", and its `details.children` lists only
  the active nodes, anywhere below the one being disposed, not just its direct children.

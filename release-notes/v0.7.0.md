English and Turkish, and an `ev ui` that follows the terminal from light to dark and back while
it runs. The language and the appearance are settings of their own, on a new Settings tab and
behind `ev settings`, kept outside the inventory.

## New

- **English and Turkish.** `ev ui` and the readable terminal output are now English by default
  and Turkish on request; until now `ev ui` was Turkish only and the command-line text English
  only. With the language on Automatic, ev uses the computer's language — on macOS the first of
  System Settings' preferred languages — and English when that is not one it speaks. Only the
  language part counts, so an English system set to the Turkish region stays English. JSON
  output and error messages stay English: they are what agents read.
- **Settings.** A Settings tab (8) in `ev ui` switches the language and the appearance with
  Enter / → and ← and applies the change to the whole screen at once. From the command line,
  `ev settings language en|tr|auto` and `ev settings theme dark|light|auto`; `ev settings`
  alone shows them, including the computer's language. They live in `~/.ev/settings.json`
  (`EV_CONFIG` to move it), not in the database, and a running `ev ui` picks up a change made
  elsewhere within a second.
- **Light and dark, live.** With the appearance on Automatic, `ev ui` follows the terminal's
  background: switch the system or terminal theme and it changes palette without a restart.
  It uses DEC mode 2031, which Ghostty, kitty and Contour support (the terminal reports each
  switch); a terminal without it is asked for its background every three seconds instead. The
  dark palette keeps the terminal's own colours; the light one uses darker tones that stay
  readable on white, where the named yellow and cyan did not.

## Changed

- **`ev ui` reads terminal input itself.** crossterm treats the terminal's light/dark report as
  an unfinished sequence and swallows the keys typed after it, so `ev ui` now parses keys,
  mouse reports and those reports on its own. Keys and the mouse work as before.

## Fixed

- **`ev show` in a terminal printed only the node's tasks** when the node belonged to one, not
  the node itself. The JSON output was right; the readable text now shows the node with its
  task lines under it.

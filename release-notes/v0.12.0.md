Built natively for every platform, in parallel, with dist: a release now takes about three and a
half minutes instead of seven, and ev can use the operating system's own APIs.

## Changed

- **Releases are built with [dist](https://opensource.axo.dev/cargo-dist/).** Each target builds
  on its own kind of machine at the same time (both macOS targets on macOS, Linux on x86 and ARM
  Linux) instead of being cross-compiled one after another on a single Linux runner with Zig.
  `brew install deligoez/tap/ev` and `brew upgrade` work as before; the archives on the GitHub
  release are now named `ev-cli-<target>.tar.xz`.
- **The system language is asked of the system.** `ev settings language auto` reads the
  preferred language through `sys-locale` (on macOS the first of System Settings' preferred
  languages, as before) instead of running `defaults`, which the cross-build had required.
- **Local times use the time zone database.** `ev ui`'s "updated" times are converted with the
  local time zone for that date, daylight saving included, instead of the offset `date` printed
  at start-up.

Adds `ev ui`, a read-only terminal browser meant to sit in a second terminal while an agent
records the inventory: the person at the shelves sees every change land as it is made.

## New

- **`ev ui`.** A tree of homes, rooms, furniture, containers and items on the left and the selected
  node's details on the right — path, code, quantity, state, pending move, lost flag, note, theme,
  fill, tags, photo paths and contents. Tabs list pending moves, disposals and lost nodes, and `/`
  searches with the same Turkish-aware folding as `ev find`. From any list, Enter jumps to the node
  in the tree.
- **Follows the database live.** The browser checks SQLite's `data_version` twice a second and
  re-reads only when another process has written. Nodes that changed are highlighted for a few
  seconds and their parents are expanded, so a move or an edit made by the agent is visible without
  hunting for it. The browser itself never writes.
- The agent skill now suggests opening `ev ui` next to the conversation.

## Upgrade notes

- No schema change; an existing `~/.ev/ev.db` works as is.
- `ev tree` output gains `updated_at` on every node and `pending_to` on nodes with a planned move.

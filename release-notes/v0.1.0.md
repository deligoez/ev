The first release of `ev`, a home inventory whose primary user is an AI agent working in
conversation with a person standing at the shelves. The person reports what is where, the agent
records it through `ev`, and either of them asks `ev` where something is. Every command prints JSON
when piped and readable text on a terminal; every failure has a fixed exit code.

## Install

```bash
brew install deligoez/tap/ev
npx skills add -g deligoez/ev   # the agent skill
```

The database is `~/.ev/ev.db`; `--db` or `EV_DB` selects another file.

## What it models

- **One tree of nodes.** Homes, rooms, furniture, containers and items are all nodes, and any node
  can hold others: a bag becomes a container the moment something is put in it. Several homes fit
  in one database (a car can be a home), and rooms can nest inside rooms.
- **Codes are the physical labels.** `K4x4-07-Ü` or `S5-01` is unique among the nodes still in the
  home, compared case- and diacritic-insensitively, and never made only of digits so it cannot be
  mistaken for an id. A code frees up again once its node has left.
- **Planned moves.** `ev move X --to Y --plan` records where something should go; the node stays put
  until the person carries it and the agent confirms with `ev done`. `ev pending` is the checklist.
- **Leaving the home.** `ev dispose --as trash|give|sell` sets a node aside, `ev gone` records that it
  actually left, and `ev gone --as` does both at once. Nothing is deleted: the record answers "did we
  sell that or give it away?".
- **Lost things.** `ev lost` keeps the last place a node was seen; `ev found` clears it in place and
  any move clears it too.
- **History.** Every change is appended to an event log that is never edited: `ev history`.

## Finding things

`ev find` searches names, codes, notes, themes and tags with Turkish-aware folding, so `cekmece`
finds "Çekmece" and `ISIK` finds "ışık". Every result carries its full path from the home down.
References resolve by id, then code, then exact name; an ambiguous one exits 4 and lists the
candidates, a partial name never resolves on its own.

## Entering a lot at once

`ev add --batch file.ndjson` (or `--stdin`) creates a whole box and its contents in one call: a line
can name an earlier line's `key` with `"in": "@key"`. A batch is written completely or not at all.

Places, ownership and lending — `ev` can now answer "I'm going to see them tomorrow, was there
anything I had to take?" — plus fixes and `ev ui` improvements found on the real inventory.

## New: places

- **A place** is a person, a household or anywhere outside the tree, with aliases: one household
  can be `Mahmutlar`, `Saliha'lar` and `Güneşler` at once. Names match case-, diacritic- and
  apostrophe-insensitively, a new name creates the place, and `ev place merge` joins two that
  turn out to be the same (`ev place add`, `alias`, `list`, `merge`).
- **Three fields point at a place:** `to` (take it there), `owner` (it is theirs, return it) and
  `with` (ours, lent out there). `ev lend X --to P` and `ev back X` manage lending; a lent node
  stays in the tree where it returns to.
- **`ev for <place>`** lists what to take, return and collect for that place, each with where it
  is now; with no argument it lists every place. The agent skill runs it whenever the person says
  they are going somewhere.
- **`return`** joins trash, give and sell as a way of leaving.

## Upgrade notes

- **Schema version 2.** An existing `~/.ev/ev.db` is migrated in place on first open; an older
  `ev` then refuses it with exit 6. Copy the file first if you may need to go back.

## Fixed

- **`ev disposals` lists a set once.** A candidate held by another candidate leaves with it, so it
  is no longer listed beside its set: each entry carries its candidate parts under `parts`, the
  text output lists them under the set, and `ev ui` shows "(+N parça)".
- **`ev tree` text output shows quantities** (`×6`) and the candidate and lost markers, as the
  other commands already did.

## `ev ui`

- **Colour for readability.** Codes, quantities, dispositions, lost and pending markers each have
  their own colour from the terminal's palette, furniture and rooms stand out from items, and list
  tabs mute the path above the node.
- **Mouse.** A click selects a row; clicking the selected row again, or a double click, expands or
  collapses it (in a list tab it jumps to the node in the tree). The wheel scrolls and clicking a
  tab title switches tabs. Hold Option (⌥) to select text in the terminal while `ev ui` runs.
- **Brand.** `ev ui` shows `EV <version>` at the left of the tab bar.
- **Item totals.** Every node in `ev tree` and `ev ui` shows how many items it holds anywhere below
  it, counting quantities (`14 eşya`); the old count of direct children is gone. JSON tree nodes
  carry it as `items`.
